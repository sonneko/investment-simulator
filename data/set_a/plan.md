# 投資計画（2026年10月16日 第3セッション終了時点）

## 1. 資産配分目標と現状
- **株式（VTI）**: 目標 18〜20%（現在 19.40%）- 許容上限20%以内で適正に推移。追加買い増しは行わず維持。
- **債券（AGG + BND）**: 目標 35〜40%（現在 35.58%：AGG 19.17% / BND 16.41%）- 高水準利回りを享受しつつ安定的インカムを確保。
- **金（GLD）**: 目標 17〜20%（現在 18.05%）- インフレ・金利変動局面での下値ヘッジ資産として堅持。
- **現金（USD）**: 目標 20〜28%（現在 26.97%）- FOMCや市場急変時の資本保全バッファーとして十分な水準をキープ。

## 2. 運用・リスク管理方針
- **リバランス規律**: 各資産が目標レンジから±3%以上乖離するか、1銘柄あたり20%の制約に抵触しそうな場合に限り、必要最小限の取引を行う。
- **資本保全の最優先**: CPI上振れに伴う利上げ懸念等の市場変動局面でもパニック売りを排し、中長期視点で分散保有を継続。
- **コスト意識**: 不必要な取引を控え、手数料の抑制と複利効果を追求する。
