# 投資計画（2026年10月21日 第3セッション終了改訂）

## 1. 資産配分目標と現状評価
- **株式（VTI）**: 目標 18〜20%（現在 19.40%）- 1銘柄20%の上限を厳守しつつ、米国市場全体の成長を中長期で享受。
- **債券（AGG + BND）**: 目標 35〜40%（現在 35.66%：AGG 19.21% / BND 16.45%）- インカム利回りを確保し、ポートフォリオ全体の価格変動を抑制。
- **金（GLD）**: 目標 17〜20%（現在 17.87%）- インフレ長期化や地政学リスクへの防御的実物資産として適正水準を維持。
- **現金（USD）**: 目標 20〜28%（現在 27.07%）- 元本保全と流動性を確保し、急激な相場変動に備えた待機資金を維持。

## 2. 運用・リスク管理方針
- **取引規律**: 全資産クラスが目標レンジ内に収まっており、リバランス基準（目標比率から±3%以上の乖離）に達していないため、不要な取引コストを避けるべくホールド姿勢を継続する。
- **監視指標**: FOMC声明、米国債利回り動向、PCEデフレーター発表を受けた市場環境の変化をモニタリングし、必要時のみ微調整を行う。
