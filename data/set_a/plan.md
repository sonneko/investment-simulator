# 投資計画（2026年10月27日 セッション3終了時点）

## 1. 資産配分現状と目標
- **株式（VTI）**: 目標 18〜20%（現在 19.37%）- 個別銘柄上限20%未満を維持。市場全体の成長を享受。
- **債券（AGG + BND）**: 目標 35〜40%（現在 36.04%：AGG 19.42% / BND 16.62%）- 安定的なインカムゲインと株式下落時のクッション。
- **金（GLD）**: 目標 17〜20%（現在 17.45%）- 実物資産としての価値保全・インフレおよび地政学リスクヘッジ。
- **現金（USD）**: 目標 20〜28%（現在 27.14%）- FOMCやPCE発表後の急変に備えた防衛的流動性。

## 2. 運用方針・監視項目
- ポートフォリオ全体が目標配分に合致しているため、無駄な売買手数料を抑制し現状維持（ホールド）を継続。
- FOMC結果、パウエルFRB議長（または後任）の会見、PCEデフレーターの結果を受けた金利・株価の変動を監視し、配分比率が目標から大きく乖離した場合にのみリバランスを実施する。
