# 投資計画（2026年10月13日 セッション3終了時点）

## 1. 資産配分目標と現状
- **株式（VTI）**: 目標 18〜20%（現在 19.59%）
- **債券（AGG + BND）**: 目標 35〜40%（現在 35.35%：AGG 19.05% / BND 16.30%）
- **金（GLD）**: 目標 17〜20%（現在 18.05%）
- **現金（USD）**: 目標 20〜28%（現在 27.01%）

## 2. 運用・リスク管理方針
- **資本保全の最優先**: 各資産クラスが理想的な比率内に維持されているため、不必要な売買は行わず取引手数料を抑制する。
- **米CPI発表通過後の対応**: 発表後のインフレ動向・長期金利変動を注視し、株式または債券がターゲットから3%以上乖離した場合にのみリバランスを検討する。
- **十分な流動性の確保**: 急変動時の下落ショック吸収および割安資産の買い増し余力として、現金比率20%以上を堅持する。
