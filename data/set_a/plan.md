# 投資計画（2026年10月27日更新）

## 1. 基本方針
- 資本保全を最優先とし、急激な資産変動を避ける。
- 各資産が目標比率から大きく乖離しない限り、取引コスト抑制のため不要な売買を避けるバイ・アンド・ホールドを基本とする。

## 2. 資産配分目標と現状
- **株式（VTI）**: 目標 18〜20%（現在 19.37%）- 米国市場全体へ分散投資し、1銘柄上限20%を厳守。
- **債券（AGG + BND）**: 目標 35〜40%（現在 36.04%：AGG 19.42% / BND 16.62%）- 高金利環境下でのインカムゲイン確保およびクッション機能。
- **金（GLD）**: 目標 17〜20%（現在 17.45%）- インフレおよび地政学的リスクへのヘッジ。
- **現金（USD）**: 目標 20〜30%（現在 27.14%）- イベント通過後の変動に備える待機資金（最低10%以上を常時確保）。

## 3. 次回以降のアクション基準
- FOMC金融政策決定会合の結果およびPCEデフレーター発表後の市場動向を注視。
- 金利・株価急変動により特定銘柄が20%を超過した場合、または現金比率が下限に近づいた場合にのみ機動的なリバランスを検討する。
