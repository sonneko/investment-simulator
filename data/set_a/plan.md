# 投資計画（2026年10月30日更新・セッション3終了時）

## 1. 基本方針
- **資本保全を最優先**とし、徹底した分散投資と低コスト運用を維持する。
- 短期的な相場ノイズに惑わされず、中長期的な視点でのバイ・アンド・ホールドを貫徹する。

## 2. 資産配分目標と現状
- **株式（VTI）**: 目標 18〜20% ／ 現状 19.47%（1銘柄20%上限を遵守）
- **債券（AGG / BND）**: 目標 35〜40% ／ 現状 35.99%（AGG 19.39% / BND 16.60%）
- **コモディティ（GLD）**: 目標 17〜20% ／ 現状 17.45%
- **現金（USD）**: 目標 20〜30% ／ 現状 27.08%（下限10%を余裕を持って維持）

## 3. 次回以降の注視点とリバランス基準
- 米国の根強いインフレ（PCE動向）および次回12月FOMCでの追加利上げ観測を注視。
- 各資産比率が目標から±3%以上乖離した場合、または単一銘柄が20%を超過した場合に限り、最小限のリバランスを実施する。
