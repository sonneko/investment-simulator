# 投資計画（2026年10月23日 第3セッション）

## 1. 資産配分目標と現状
- **株式（VTI）**: 目標 18〜20%（現在 19.33%）- 米国広範な市場成長を享受。上限20%未満を厳守。
- **債券（AGG + BND）**: 目標 35〜40%（現在 36.05%：AGG 19.42% / BND 16.63%）- 米長期金利低下局面でも安定したインカムゲインとクッション機能を提供。
- **金（GLD）**: 目標 17〜20%（現在 17.50%）- 実物資産としてのインフレ・地政学ヘッジ機能。
- **現金（USD）**: 目標 20〜28%（現在 27.12%）- 資本保全と下落時の流動性を確保（下限10%を大幅に上回る安全水準）。

## 2. 運用方針・監視項目
- すべての保有資産が目標配分内に収まっているため、無駄な売買手数料（0.10%）を回避すべくホールドを維持。
- FOMC前の市場動向（政策金利動向、10年債利回り5%前後の攻防）およびインフレ指標の推移を引き続き監視し、許容変動幅を超えた場合のみ段階的なリバランスを行う。
