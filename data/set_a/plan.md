# 投資計画（2026年10月27日更新）

## 1. 基本方針
- 資本保全を最優先とし、急激な資産変動・ドローダウンを避ける。
- 各資産が目標比率から大きく乖離しない限り、取引手数料の抑制を意識して不要な売買を控えるバイ・アンド・ホールドを貫徹する。

## 2. 資産配分目標と現状
- **株式（VTI）**: 目標 18〜20%（現状 19.38%）- 米国市場全体への分散投資。1銘柄上限20%を厳守。
- **債券（AGG + BND）**: 目標 35〜40%（現状 36.01%：AGG 19.41% / BND 16.60%）- 安定的なインカムゲイン確保およびボラティリティ抑制。
- **金（GLD）**: 目標 17〜20%（現状 17.49%）- インフレおよび地政学的・テールリスクへのヘッジ。
- **現金（USD）**: 目標 20〜30%（現状 27.12%）- 市場急変時のショックアブソーバー兼クッション（最低10%以上を常時維持）。

## 3. 次回以降のアクション基準
- FOMC結果公表および米PCEデフレーター発表後の金利・株価の反応を確認。
- 特定銘柄が20%の上限を超過した場合、または相場急変により目標資産配分から大きく逸脱した場合に限定してリバランスを実施する。
