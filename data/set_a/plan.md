# 投資計画（2026年10月22日 第3セッション維持）

## 1. 資産配分目標と現状
- **株式（VTI）**: 目標 18〜20%（現在 19.47%）- 上限20%を厳守しつつ、低コストインデックスで米国経済の持続的成長を享受。
- **債券（AGG + BND）**: 目標 35〜40%（現在 35.61%：AGG 19.18% / BND 16.42%）- 10年債利回り5.1%水準の高いインカム利回りを確保し、ポートフォリオ全体の価格変動を抑制。
- **金（GLD）**: 目標 17〜20%（現在 17.90%）- インフレ長期化懸念や地政学リスクに対する実物資産ヘッジとして維持。
- **現金（USD）**: 目標 20〜28%（現在 27.02%）- 元本保全と十分な流動性を維持し、相場の急変時に備える。

## 2. 運用方針・監視項目
- 目標配分からの乖離が軽微であるため、不要な売買手数料を抑える方針を徹底。
- FOMC金融政策決定およびパウエルFRB議長会見、米10年債利回りの推移、次回CPI/PCEなどのインフレ指標を注視し、レンジを逸脱した場合のみリバランスを実行する。
