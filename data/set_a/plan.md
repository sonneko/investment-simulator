# 投資計画（2026年10月22日 第3セッション完了）

## 1. 資産配分目標と現状
- **株式（VTI）**: 目標 18〜20%（現在 19.47%）- 上限20%を厳守しつつ、低コストインデックスで米国経済の持続的成長を享受。
- **債券（AGG + BND）**: 目標 35〜40%（現在 35.61%：AGG 19.18% / BND 16.42%）- 10年債利回り5%超水準の高いインカム利回りを確保し、ポートフォリオ全体の価格変動を抑制。
- **金（GLD）**: 目標 17〜20%（現在 17.90%）- インフレ長期化懸念や地政学リスクに対する実物資産ヘッジとして維持。
- **現金（USD）**: 目標 20〜28%（現在 27.02%）- 元本保全と十分な流動性を維持し、相場の急変時に備える。

## 2. 運用方針・監視項目
- 各資産が理想的な配分レンジ内に収まっているため、不要な売買手数料を抑える方針を徹底。
- 次回FOMCの政策決定、米10年債利回りの変動、ならびにインフレ指標（CPI/PCE）を注視し、配分上限20%の超過や現金比率20%割れなどが発生した場合にのみ限定的なリバランスを検討する。
