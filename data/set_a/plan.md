# 投資計画（2026年10月28日更新）

## 1. 基本方針
- 資本保全を最優先とし、ボラティリティを抑制した安定的なリターンを追求。
- 目標配分からの大幅な乖離がない限り、手数料コスト削減のためバイ・アンド・ホールドを貫徹。

## 2. 資産配分目標と現状
- **株式（VTI）**: 目標 18〜20%（現状 19.43%）- 1銘柄上限20%未満を厳守。
- **債券（AGG + BND）**: 目標 35〜40%（現状 35.93%：AGG 19.36% / BND 16.57%）- ポートフォリオの安定化とインカム確保。
- **金（GLD）**: 目標 17〜20%（現状 17.60%）- 実質金利・インフレ変動リスクへの緩衝材。
- **現金（USD）**: 目標 20〜30%（現状 27.04%）- 流動性確保およびショックアブソーバー（最低10%維持）。

## 3. 次回以降のアクション基準
- FOMC声明文およびパウエル議長会見後の米金利・株式市場の反応をモニタリング。
- いずれかの資産が目標比率から±3%以上乖離した場合、または1銘柄20%の上限に達した場合にのみリバランスを実施する。
