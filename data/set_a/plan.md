# 投資計画（2026年10月22日 第3セッション改訂）

## 1. 資産配分目標と現状
- **株式（VTI）**: 目標 18〜20%（現在 19.47%）- 上限20%を厳守しつつ、米国市場全体の成長を中長期で享受。
- **債券（AGG + BND）**: 目標 35〜40%（現在 35.61%：AGG 19.18% / BND 16.42%）- 10年債利回り5%台の高水準なインカム利回りを確保し、ポートフォリオのボラティリティを抑制。
- **金（GLD）**: 目標 17〜20%（現在 17.90%）- インフレ長期化および地政学的リスクに対する安全資産として適正比率を維持。
- **現金（USD）**: 目標 20〜28%（現在 27.02%）- 資本保全と流動性を担保し、相場急変時のバッファーおよび将来の押し目買い余力として確保。

## 2. 運用・リスク管理方針
- **取引規律**: 各資産が目標レンジ内に収まっており、乖離幅が小さいため不要な手数料コストを避けるべくホールドを維持する。
- **次回以降の注目指標**: FOMC声明およびパウエルFRB議長会見、米10年債利回りの5.1%台での推移、次回発表のPCEデフレーターおよびCPIインフレ指標を継続監視し、金利動向に応じて債券比率の微調整を検討する。
