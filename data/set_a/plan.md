# 投資計画（2026年10月30日更新）

## 1. 基本方針
- 資本保全を最優先とし、低ボラティリティかつ安定的なトータルリターンを追求。
- コスト管理を徹底し、目標配分からの有意な乖離が発生しない限りバイ・アンド・ホールドを貫徹。

## 2. 資産配分目標と現状
- **株式（VTI）**: 目標 18〜20%（現状 19.47%）- 1銘柄上限20%未満を順守。
- **債券（AGG + BND）**: 目標 35〜40%（現状 35.99%：AGG 19.39% / BND 16.60%）- 安定インカム利回りを確保。
- **金（GLD）**: 目標 17〜20%（現状 17.45%）- インフレ・地政学リスク対策。
- **現金（USD）**: 目標 20〜30%（現状 27.08%）- 不測の事態への耐性と流動性確保（禁止事項である10%以下を大幅に上回る安全水準）。

## 3. 次回以降の注視点・アクション基準
- 米国PCEインフレ加速に伴う金利動向および年末にかけての金融政策（FOMC）見通しを継続監視。
- いずれかの資産が目標配分比率から±3%以上乖離した場合、または単一銘柄が20%を超過した場合にのみ最小限のリバランスを実施。
