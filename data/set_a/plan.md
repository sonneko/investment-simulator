# 投資計画（2026年10月26日 セッション3終了時点）

## 1. 資産配分現状と目標
- **株式（VTI）**: 目標 18〜20%（現在 19.28%）- 個別銘柄上限20%未満を遵守。市場全体への分散投資を維持。
- **債券（AGG + BND）**: 目標 35〜40%（現在 36.09%：AGG 19.45% / BND 16.64%）- 安定インカムと市場急変時のクッション機能を担う。
- **金（GLD）**: 目標 17〜20%（現在 17.44%）- インフレ・地政学リスク・通貨変動リスクのヘッジ。
- **現金（USD）**: 目標 20〜28%（現在 27.20%）- FOMC等の重要マクロイベント通過待ちおよび元本保全のための流動性。

## 2. 運用方針・監視項目
- 各資産の配分が理想的な水準にあるため、不要な売買手数料を抑えるべくホールドを維持。
- 今週発表されるFOMC政策金利発表、パウエル議長記者会見、米PCEデフレーターの内容を慎重に確認し、利回り急変動や市場の動揺があれば現金バッファーを活用して段階的なリバランスを検討する。
