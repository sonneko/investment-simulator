# 利益志向ポートフォリオ 運用計画 (2026-09-14更新)

## アセットアロケーション方針
- **QQQ (ナスダック100 ETF)**: 52〜54%（テック・成長株全体のモメンタムを捕捉）
- **NVDA (エヌビディア)**: 38〜40%（Rubin/BlackwellによるAIインフラ独占的需要を最大享受、上限40%厳守）
- **BTC-USD (ビットコイン)**: 6〜8%（ETF連続純流入による暗号資産ラリーを享受、上限10%）
- **Cash (USD)**: 1〜2%（急変時のクッションおよび待機資金）

## 運用戦略
- **積極的フルインベストメント継続**: S&P500をアウトパフォームするため、AI半導体・メガキャップテック・BTCの高モメンタム資産をフル保有。
- **厳格なリスク管理**: 直近高値から10%超の下落を記録した銘柄は速やかに損切りを実行。NVDAの比率が40%を超過した場合は即座に部分利確。
- **資金管理**: 追加トレード時は現金残高の50%以内ルールを徹底。
