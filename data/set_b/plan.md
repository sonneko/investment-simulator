# 利益志向ポートフォリオ 運用計画 (2026-11-11改定)

## 資産配分ターゲット
- **QQQ (ナスダック100 ETF)**: 50〜55%（テック市場のコア成長を捕捉）
- **TSM (TSMC ADR)**: 10〜15%（巨額CapExとAI半導体需要の直接的恩恵を享受する主軸モメンタム銘柄）
- **NVDA (エヌビディア)**: 10〜15%（ポジションを34株まで圧縮し底入れを確認するまで抑制）
- **BTC-USD (ビットコイン)**: 5〜8%（暗号資産枠としてアップサイドを狙う）
- **Cash (USD)**: 10〜15%（急落局面での押し目買いやカタリスト対応の機動資金）

## 運用・リスク管理方針
- **強弱銘柄の選別ローテーション**: 相対的に軟調なNVDAから、強烈な逆行高を見せるTSMへ積極シフト。
- **ナンピン禁止と迅速な損切り**: 下落中のNVDA追加購入は厳禁とし、安値を割り込む場合は即座に撤退・削減。
- **余力管理の徹底**: 1トレードの買付額は現金総額の50%以内を守り、十分な流動性を担保する。
